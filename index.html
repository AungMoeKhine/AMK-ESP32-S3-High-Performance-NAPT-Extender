ESP32-S3 Wi-Fi Extender

Install the high-performance Long Range (LR) Wi-Fi repeater firmware onto your ESP32-S3 board directly from your web browser.

  1. Connect your ESP32-S3 via a USB data cable.
  2. Ensure you are using Google Chrome or Microsoft Edge.
  3. Click Install below and choose your board's COM port.
⚠️ Note for ESP32-S3: If the installer fails to connect, press and hold the BOOT button, tap the RST/RESET button once, then release BOOT to enter bootloader mode.
